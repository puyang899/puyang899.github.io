IBM CLOUD MANAGER WITH OPENSTACK

IBM® Cloud Manager with OpenStack provides an open and comprehensive Infrastructure as a Service cloud solution. It is a self-service portal for simplified cloud management for the Cloud end-user. It enables the user to work with virtual appliances and workloads focusing on both the end user's perspective and the IT administrator’s perspective.

  • Single Edit
  • Column Edit

UNDERSTAND THE USERS

During the design process of the IBM Design Thinking, this project focused on two types of users: the developer (the end-user) and the IT administrator. We interviewed different types of users to understand how they currently collaborate, set up, build and maintain the cloud services and find out the pain points during their current workflows.
